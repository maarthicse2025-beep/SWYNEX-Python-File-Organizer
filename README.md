# SWYNEX - Python Automation Tool

## 📌 Objective
To automate repetitive tasks like File Processing, Data Transformation, Backup, and Report Generation using Python.

## ✨ Features
- File Processing - Automatically creates data/input.txt with sample data
- Data Transformation - Cleans data, converts names to uppercase and calculates total quantity
- Backup Files - Automatically creates backup folder and saves backup with date & time
- Report Generation - Automatically creates report.txt with full summary
- Menu based - User can choose Run Automation or Exit

## 🛠️ Tools Used
- Python
- os module
- shutil module
- datetime module
